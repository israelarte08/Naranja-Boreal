NARANJA BOREAL — PROTOTIPO WEB Y CHATBOT

ARCHIVO PRINCIPAL
- index.html: página web adaptable a celular y computadora, con catálogo ilustrativo y chatbot de preguntas frecuentes integrado.

CÓMO PROBARLO
1. Abre index.html en Chrome o cualquier navegador moderno.
2. Pulsa el botón naranja “Consultar” para abrir el chatbot.
3. Prueba preguntas como “¿Qué productos tienen?”, “¿Cuánto cuesta?”, “¿Cómo hago un pedido?” y “¿Hacen entregas?”.

IMPORTANTE
- Esta es una demostración funcional local. Aún no está publicada en internet y no tiene una URL pública.
- El chatbot responde mediante reglas locales; no está conectado a IA ni a un sistema de atención humana.
- Los productos se muestran como líneas ilustrativas. No se han inventado precios, número de WhatsApp ni stock real.
- Antes de presentar, añade fotos reales si las tienes, precios confirmados y los datos de contacto autorizados.

CÓMO PUBLICAR GRATIS (OPCIÓN: 
GITHUB PAGES)
1. Crea una cuenta en https://github.com/ si no tienes una.
2. Crea un repositorio público llamado naranja-boreal.
3. Sube el archivo index.html al nivel principal del repositorio.
4. En Settings > Pages, selecciona Deploy from a branch, elige main y /(root), y guarda.
5. Espera a que GitHub Pages genere la dirección pública. Abre esa URL desde un teléfono sin iniciar sesión para verificarla.

Para alojar el chatbot separado o conectar un modelo de IA se necesitaría una plataforma de chatbot y configurar su 
publicación. Este prototipo integrado sirve como demostración inicial del concepto.
